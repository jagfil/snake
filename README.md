# Snake "Sausage dog"
A classic Snake game featuring unique visual style, developed in C++ using the SFML library.
Player control a dachshund using the arrow keys or WASD, avoiding walls and its own body while collecting bones, balls, and socks to grow in size.

# Features:
- Object-oriented design with separate classes for game logic, the dachshund, and collectible items.
- Collision detection with walls and the dachshund's own body.
- Randomized item placement and selection.
- Current score and high-score tracking.
- Custom sprites and a themed graphical interface.
